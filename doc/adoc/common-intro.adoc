Documentation format

The TSDuck guides are built using https://asciidoctor.org[asciidoctor], from a
set of text files which are maintained alongside the source code, in the same
`git` repository.

This guide is formatted for HTML. The file xref:{docname}.html[] is monolithic
and self-sufficient, without reference to external images. Therefore, this HTML
file can be downloaded, saved, and copied, as long as the license and content
are not modified.

A PDF version xref:{docname}.pdf[] is also available. However, due to
limitations in the PDF generator of asciidoctor, the rendering is sometimes not
as good as the HTML document.
