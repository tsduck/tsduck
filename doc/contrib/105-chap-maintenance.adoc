== Maintaining TSDuck Code

This chapter is meant to help TSDuck maintainers.

It covers various technical topics such as the modular structure of the
project, adding new signalization tables and descriptors, the internal design
of the `tsp` utility, the support of hardware devices, etc.

This chapter does not pretend to cover all technical topics in TSDuck and
remains a work in progress. As usual, remember that "the answer is in the code".
